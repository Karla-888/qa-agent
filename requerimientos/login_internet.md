# RF-002 Autenticacion en portal de practica

El sistema debe permitir al usuario autenticarse con nombre de usuario y contrasena.

- Se valida el nombre de usuario contra los registros existentes.
- Se valida la contrasena asociada al usuario.
- Si el usuario no existe, se muestra un mensaje indicandolo.
- Si la contrasena es incorrecta, se muestra un mensaje indicandolo.
- Al autenticarse correctamente, el sistema redirige al area segura y muestra un mensaje de bienvenida.
- El area segura ofrece la opcion de cerrar sesion.
