# RF-001 Inicio de sesión

El sistema debe permitir al usuario autenticarse con correo y contraseña.

- El correo debe tener formato válido.
- La contraseña debe tener mínimo 8 caracteres, al menos una mayúscula y un número.
- Tras 3 intentos fallidos, la cuenta se bloquea 15 minutos.
- Un usuario inactivo no puede iniciar sesión; se muestra "Usuario deshabilitado".
- Al autenticarse correctamente, el sistema redirige al menú principal.
